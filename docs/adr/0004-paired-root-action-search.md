# ADR-0004: 配对根动作评估

## 状态

已采纳（2026-09-21），取代 [ADR-0003](0003-team-aware-so-ismcts.md) 的生产默认，
但保留其 SO-ISMCTS 实现作研究与回归对照。

## 背景

SO-ISMCTS 在 32–64 次低预算下要同时支付根动作探索、渐进扩展和深层节点访问。
高精度动作价值基线覆盖 200 个固定局面、1,137 个动作和每动作 400 次出牌：

- `argmax32` regret `0.0449`，约 `105.8ms`；
- `search32` regret `0.0571`，约 `237.4ms`；
- `search64` regret `0.0550`，约 `470.2ms`。

树搜索没有优于均分根动作预算。随后验证的配对根评估 `flat32` regret 为
`0.0487`（约 `126ms`），与 `argmax32` 差异不显著，并显著优于 greedy；
`flat96` regret 为 `0.0440`，相对旧 `search64` 的配对差为 `-0.0109`
（`t=-2.10`）。严格匹配生产参数后，`root32/root96` regret 分别为 `0.0493`
和 `0.0424`；`root96` 相对旧 `search64` 的配对差仍显著（`t=-2.48`），
相对 `argmax32` 则无显著差异。
逐步淘汰的 `race32/race64` 均弱于均匀分配，因此不采用。

## 决策

职业档和戴长胜档默认使用配对根动作评估：

1. 每轮从根玩家信息集采样一个隐藏世界。
2. 所有根动作应用到该世界的独立副本，共享随机条件以降低动作差值方差。
3. 候选为最多 6 个分层搜索动作，并强制覆盖合法过牌和 greedy 实际动作。
4. 预算均匀分配，不在 2–4 个样本后淘汰动作。
5. rollout 使用轻量档 1；动作风格先验按访问次数衰减，不作硬否决。
6. 职业档最多 32 次评估或 240ms；戴长胜档最多 96 次或 420ms。
7. 中残局闸门继续保留；旧 SO-ISMCTS 可通过 `search_mode="tree"` 显式启用。

## 后果

### 优点

- 计算直接用于根动作比较，避免低预算下的树结构开销。
- 同一隐藏世界内的动作结果形成配对样本，减少世界采样噪声。
- 过牌和快速策略动作不会因候选截断而缺失。
- 职业档固定预算约减半；8 个 seed、座位互换的 16 局 Arena 对旧 tree64
  为 `8:8`、平均升级差 `0.0`，提供小样本非回退证据。
- 生产时钟口径的 4 个 seed、8 局同样为 `4:4`；root32 决策平均 `105ms`、
  p95 `247ms`、最大 `260ms`。

### 代价

- 不再显式规划多层公开动作序列，可能漏掉必须经过多手才显现的战术。
- rollout 仍有较大方差，单次评估无法视为确定性牌力证明。
- 戴长胜既有风格参数来自旧搜索调参，虽保留为弱先验，仍应重新积累留出数据。

## 验证

- `scripts/action_value_baseline.py` 支持 `flat32/flat64/flat96`、失败的
  `race32/race64` 和 rollout/先验消融，并保存逐局面 regret、置信区间、
  配对 t 值与耗时。
- 单元测试验证候选覆盖、固定 seed 可复现、评估预算守恒、策略模式切换和配置上限。
- 最终强度仍以同 seed、座位互换的 Arena 为准；动作价值基线不能替代整局胜率。
