# ADR-0003: 团队感知 SO-ISMCTS

## 状态

已采纳（2026-07-27），取代 [ADR-0002](0002-is-mcts.md) 的生产搜索设计。

## 背景

M3 的单次确定化会让一次随机猜牌决定整棵树，容易形成策略融合偏差；标准
MCTS 若始终最大化根玩家收益，还会在对手节点假设对手主动帮助根玩家。简单
截取最低成本的前 N 个动作，也会漏掉立即出完、控场牌和炸弹等关键分支。

掼蛋又是固定搭档游戏。搜索目标不仅是个人尽快走完，还要考虑队友名次、升级
幅度、冲 A 和比赛胜负。因此生产搜索需要同时解决隐藏信息、团队对抗、候选
覆盖和交互延迟。

## 决策

职业档和戴长胜档采用团队感知的 Single-Observer Information Set MCTS：

1. 搜索树只保存公开动作序列，不绑定任何一次隐藏牌分配。
2. 每次模拟都从根玩家信息集重新采样一个完整且守恒的隐藏世界。
3. 根玩家与队友节点最大化根队价值，对手节点最小化根队价值。
4. 只有当前采样世界中的合法动作参与选择，并记录动作 availability。
5. 用 PUCT 风格先验和 progressive widening 在有限预算内逐步展开候选。
6. rollout 和叶节点评估统一以根队为视角，纳入名次、升级、冲 A、控场、
   剩余手牌结构和控制牌。

### 信息边界

确定化只能读取根玩家手牌和公开信息：已出牌、当前牌墩、剩余张数、报牌、
贡还牌事件、比赛级别及历史名次。公开贡还牌是硬约束；玩家面对可压牌而过牌
是严格非零的软证据。任何采样都不得读取或据此校正对手真实手牌。

### 动作覆盖

候选生成按稳定牌型键去重，并分层保留立即出完、过牌、最低成本压制、最大
减手、强控场非炸弹、各牌型代表以及最小和最大炸弹。渐进扩展决定某次访问
实际开放多少动作，避免固定 top-N 过早丢失战术分支。

### 预算与风格

职业档上限为 64 次模拟或 240ms，最多 10 个候选，树深 12；戴长胜档上限为
96 次模拟或 420ms，最多 12 个候选，树深 14。生产游戏使用时钟预算，固定
迭代 Arena 则分别使用 64 / 96 次模拟，保证跨机器回归可复现并覆盖完整搜索上限。

戴长胜的炸弹、控场和队友意识参数来自镜像自对弈筛选，只调整搜索先验。搜索
结束后不再用硬规则把首选动作改为过牌。

## 后果

### 优点

- 多个隐藏世界共享统计，降低单次确定化偏差。
- 对手节点采用对抗目标，团队协作与阻断行为更符合真实牌局。
- 分层候选和渐进扩展兼顾战术覆盖与响应时间。
- 生产预算、固定迭代回归、镜像 Arena 和整场过 A 评测形成可审计闭环。

### 代价

- 搜索结果仍有采样方差，小样本胜率必须配合 Wilson 区间解读。
- 时钟预算下模拟次数受机器负载影响，不能用于逐动作完全复现。
- 在线采样不维护跨回合持久信念；更精细的贝叶斯更新仍可作为后续迭代。

## 验证

- 单元测试覆盖隐藏牌不泄漏、牌守恒、贡还牌约束、过牌软证据、availability、
  团队节点选择、候选覆盖和预算上限。
- Arena 对同一 seed 交换候选与基线所在固定队，报告胜率、Wilson 95% 区间、
  Elo、升级差和候选决策延迟。
- 整场模式从级牌 2 连续执行升级、进贡、还贡和过 A，以最终比赛胜负计分。
