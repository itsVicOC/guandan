# v0.8.1-beta.1 公测版 Release Notes

发布日期：2026-09-16

## 发布定位

`v0.8.1-beta.1` 聚焦桌面体验与比赛规则的一致性：GUI 全面升级为现代国风牌桌视觉，连牌规则按固定三连对、固定两组三张钢板及自然点数口径完成校准。

Python 包版本为 `0.8.1b1`。

## 主要更新

### 全新桌面牌桌

- 大厅、难度、存档、历史、回放、规则和实战页面统一为漆黑、翡翠与暖金组成的视觉体系。
- 大厅使用原生矢量绘制金属桌沿、渐变桌布、四方席位、手牌与牌背，高清屏下保持锐利且无需额外图片资源。
- 实战页强化桌面纵深、回合焦点、搭档队伍、报单 / 报双和牌墩信息层级。
- 扑克牌新增纸张渐变、阴影、选中光效与更清晰的花色；牌背与缩略牌同步重绘。
- `1280×860` 与最低 `1080×760` 窗口均完成逐页视觉验收。

### 连牌规则校准

- 2 按自然点数参与顺子、三连对、钢板与同花顺；普通级牌在这些连牌中也按自然点数使用。
- 三连对固定为 3 对，钢板固定为 2 组三张。
- A 可在三连对和钢板中作为最小点数，例如 `AA-22-33`、`AAA-222`；不能跨越形成其他非法窗口。
- 规则说明、共享界面文案和回归测试同步更新。

## 桌面下载

- `Guandan-v0.8.1-beta.1-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.1-beta.1-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.1-beta.1-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.1-beta.1-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.1b1-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。
