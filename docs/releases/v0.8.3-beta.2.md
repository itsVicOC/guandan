# v0.8.3-beta.2 公测版 Release Notes

发布日期：2026-09-24

本版改进手牌操作，并在玩家出完手牌后显示对家剩余手牌。Python 包版本为 `0.8.3b2`。

## 手牌操作

- GUI 与 TUI 可锁定、解锁已选中的合法牌型。锁定牌组在切换智能理牌方案时保持独立；牌组不完整或开始新小局时自动解除。
- GUI 可以按住手牌横向拖动，连续选择或取消多张牌；不在自己回合时也能提前选牌、整理和锁定牌组。
- GUI 用锁形轨道、TUI 用锁图标标识锁定牌组。锁定只影响当前小局的手牌显示，不改变出牌规则或存档。

## 对家剩余手牌

- 你的手牌出完后，GUI 与 TUI 会显示对家的当前剩余手牌；GUI 本局结算区也会显示。
- 下一局开始发牌时，对家手牌重新隐藏。

## 验证与下载

- 504 项自动化测试、Ruff、mypy 与 GUI/TUI 视觉检查通过。
- 本地 Apple Silicon 桌面包已通过打包启动、arm64 架构和应用签名完整性检查。
- Windows x64、Linux x64、macOS Intel 与 Apple Silicon 桌面包由标签发布工作流分别构建和验证，全部成功后附到本 Release。

- `Guandan-v0.8.3-beta.2-windows-x64.zip`：Windows x64。
- `Guandan-v0.8.3-beta.2-macos-arm64.zip`：Apple Silicon Mac。
- `Guandan-v0.8.3-beta.2-macos-x64.zip`：Intel Mac。
- `Guandan-v0.8.3-beta.2-linux-x64.tar.gz`：Linux x64。
- `guandan-0.8.3b2-py3-none-any.whl`：Python 包。
- `SHA256SUMS.txt`：发布资产校验值。

桌面包包含 Python、PySide6 和运行依赖。公测包未进行商业代码签名或 Apple 公证，首次启动时操作系统可能要求确认。
