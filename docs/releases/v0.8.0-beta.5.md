# v0.8.0-beta.5 公测版 Release Notes

发布日期：2026-07-27

## 发布定位

`v0.8.0-beta.5` 是桌面包热修复版本，修复 `v0.8.0-beta.4` 中选择 AI 难度后无法开始游戏的问题。Python 源码安装不受该打包缺陷影响，但桌面包用户应升级到本版本。

Python 包版本为 `0.8.0b5`。

## 主要更新

- PyInstaller 构建现在显式收集 `guandan.ai.strategies` 及全部五档 AI 策略模块。
- 发布包 smoke test 会在冻结可执行文件中逐档实例化新手、进阶、高手、职业和戴长胜 AI，再验证 GUI 进程稳定启动。
- 难度页会捕获策略模块、配置文件或配置数据加载错误，并向用户显示明确提示。
- 新增 Qt 真实鼠标点击难度卡片的回归测试，覆盖成功开局和策略加载失败两条路径。

## 桌面下载

- `Guandan-v0.8.0-beta.5-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.0-beta.5-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.5-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.5-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.0b5-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。

## 验证

- 419 项自动化测试通过。
- Ruff、mypy、工作流 YAML 与差异检查通过。
- macOS Apple Silicon 本地冻结包确认包含五档 AI 策略，并通过增强版 packaged smoke test。
- Windows、Linux、macOS Intel 与 macOS Apple Silicon 将由标签发布工作流分别原生构建和验证。
