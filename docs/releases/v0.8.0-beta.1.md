# v0.8.0-beta.1 公测版 Release Notes

发布日期：2026-07-01

## 发布定位

`v0.8.0-beta.1` 是 M8 桌面 GUI 首个公测版本，在既有 TUI / CLI / 规则引擎基础上加入 PySide6 原生桌面界面，并补齐共享牌局 session 层。

Python 包版本为 `0.8.0b1`。

## 主要更新

- 新增 `guandan-gui` 桌面 GUI 入口，包含大厅、难度选择、牌局、继续存档、历史战绩和规则说明页面。
- 新增 `guandan.ui.session` 共享牌局控制层，供 GUI 复用新局、AI 推进、出牌 / 过牌、下一局、进贡还贡、存档和历史记录逻辑。
- GUI 牌局页采用东 / 南 / 西 / 北固定方位显示：默认玩家坐东，西家在对面，北家在右侧，南家在左侧。
- GUI 手牌使用自绘牌面，红心 / 方片为红色，黑桃 / 梅花为黑色，并放大中央花色与中文花色名，提升辨识度。
- GUI 开局 27 张手牌会按窗口宽度自动换行并保持稳定高度，避免默认窗口下手牌显示不全。
- GUI 支持鼠标选牌、出牌、过牌、提示、清空选择、下一局和返回大厅。
- PySide6 作为 `gui` optional dependency 提供；未安装 GUI 依赖时，CLI / TUI 不会被 Qt 依赖牵连。
- Python 运行下限提升为 3.10+，包元数据、README、CHANGELOG 和入口版本号统一更新。

## 验证

本版本发布前已通过：

```bash
ruff check src tests --no-cache
mypy src
python -m compileall -q src tests
git diff --check
pytest -q -p no:cacheprovider
QT_QPA_PLATFORM=offscreen pytest tests/test_gui_session.py::test_gui_window_smoke_offscreen
python -m guandan.cli --help
python -m guandan.smoke 3 0
pip wheel . --no-deps --no-build-isolation
```

测试结果：`329 passed, 1 skipped`；GUI smoke 在安装 PySide6 的 Python 3.12 环境单独通过。

## 公测关注点

- 继续关注 GUI 牌局中手牌选择、出牌、过牌、下一局和存档恢复是否有交互断点。
- 继续关注不同 macOS / Linux 字体环境下红黑花色与中文花色名的清晰度。
- 若遇到 GUI 与 TUI 在规则表现上的差异，请记录当前级牌、出牌区、各家手牌数和最近一轮行动。
