# v0.8.0-beta.6 公测版 Release Notes

发布日期：2026-07-27

## 发布定位

`v0.8.0-beta.6` 优化跨局的贡还牌流程：下一局会先发牌并展示新手牌，再进入进贡 / 还贡阶段；贡还牌信息会作为本局公开信息持续显示在牌桌上。

Python 包版本为 `0.8.0b6`。

## 主要更新

- 点击“下一局”后先展示新发的 27 张手牌，再开始贡还牌流程。
- 收贡玩家选择还牌前，可以从完整手牌中看到刚收到的贡牌。
- GUI 与 TUI 的中央牌桌会整局展示进贡牌、还贡牌和双方来源去向；抗贡状态同样持续公开。
- 公开贡还信息由对局事件历史恢复，刷新、存档读取和继续游戏后不会丢失。
- 贡还阶段暂停正常出牌操作和回合高亮，避免误操作与状态混淆。

## 桌面下载

- `Guandan-v0.8.0-beta.6-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.0-beta.6-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.6-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.6-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.0b6-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。

## 验证

- 420 项自动化测试通过。
- Ruff、mypy、视觉验收和差异检查通过。
- Windows、Linux、macOS Intel 与 macOS Apple Silicon 将由标签发布工作流分别原生构建和验证。
