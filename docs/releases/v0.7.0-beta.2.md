# v0.7.0-beta.2 公测版 Release Notes

发布日期：2026-06-13

## 发布定位

`v0.7.0-beta.2` 是公测阶段的稳定性补丁版本，重点修复 TUI 牌局页在牌权切换后可能显示出牌/过牌顺序异常的问题，并补强逆时针行牌的自动化回归测试。

Python 包版本为 `0.7.0b2`。

## 主要更新

- 修复 TUI 从整局历史反查当前桌面出牌者/过牌者的问题，避免旧轮次过牌或相同牌型污染当前轮显示。
- 当前桌面显示改为只基于当前 trick 的尾部事件重建出牌者和过牌顺序。
- 状态栏“最大牌玩家”和中央桌面玩家标注统一使用当前 trick 解析结果。
- 补充规则层测试：任意座位先手出牌后都必须按逆时针推进。
- 补充规则层测试：后手赢得牌权并开启新一轮后，继续按逆时针推进。
- 补充 TUI 测试：任意真人座位下，AI 新 leader 连续行动必须按逆时针推进到真人回合。

## 验证

本版本发布前已通过：

```bash
.venv/bin/ruff check src tests
.venv/bin/mypy src
.venv/bin/pytest
```

测试结果：`237 passed`。

## 公测关注点

- 若仍观察到疑似顺序异常，请优先记录当时四家座位、当前最大牌玩家、桌面显示日志和上一轮收牌方。
- 后续将继续加强 TUI 对当前轮、历史轮和行动日志的可视区分。
