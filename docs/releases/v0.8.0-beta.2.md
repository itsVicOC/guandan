# v0.8.0-beta.2 公测版 Release Notes

发布日期：2026-07-24

## 发布定位

`v0.8.0-beta.2` 聚焦桌面 GUI 的整体视觉与交互重构，同时收紧回放、存档、统计和牌局切换的可靠性边界。

Python 包版本为 `0.8.0b2`。

## 主要更新

- 桌面 GUI 重建为现代四人牌桌：统一大厅和次级页面视觉，新增绿色牌桌、队伍座位状态、牌背、缩略牌墩与清晰的行动反馈。
- 27 张手牌改为自适应重叠单排；选中牌会上浮高亮，当前级牌按“大王、小王、级牌、A、K...”顺序展示。
- GUI 历史战绩支持逐事件回放，GUI 与 TUI 共享事件描述和回放状态，导航使用缓存快照减少重复计算。
- 新增完整事件流重放；存档加载会交叉校验摘要、状态快照、事件重放与 108 张牌守恒，损坏或伪造数据会被拒绝。
- 存档与 Profile 升级到 2.0，旧格式可迁移；历史保存按 `game_id` 幂等覆盖，`game_id` 改用 UUID 并限制安全字符。
- 未指定 seed 时记录实际随机种子，确保牌局可确定性回放。
- 离开牌桌会停止 AI 定时器，AI 行动异常不再无限重试；上一局持久化失败时禁止进入下一局。
- 胜负统计按固定搭档队伍的头游结果计算，修复个人名次导致的误判。
- TUI 牌局流程迁移到共享 `GameSession`，GUI、TUI 与持久化层使用一致的行牌和下一局逻辑。

## 验证

本版本发布前执行：

```bash
ruff check src tests --no-cache
mypy src
python -m compileall -q src tests
pytest -q
git diff --check
uv build --wheel
```

测试覆盖 Python 3.10 与 Python 3.12，并包含 PySide6 GUI smoke、事件回放、存档完整性、统计和牌局 session 回归。

## 公测关注点

- 继续关注不同分辨率、缩放比例和系统字体下的牌桌布局与手牌可读性。
- 继续验证长局、连续多局和异常退出后的存档恢复及回放一致性。
- 若发现无法载入旧存档，请保留原文件并附上版本号和错误提示，避免覆盖原始现场。
