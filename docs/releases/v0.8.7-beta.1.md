# v0.8.7-beta.1 公测版 Release Notes

发布日期：2026-10-09

本版落实近期改造的整体审查，重点修复跨局存档与前端后台任务，统一 AI 搜索预算和研究验收工具。Python 包版本为 `0.8.7b1`，支持 Python 3.10+。

## 跨局与存档恢复

- GUI/TUI 与整场评测共用下一局发牌逻辑，保留双方冲 A 失败次数、规则版本和完整发牌事件，覆盖贡还牌、抗贡及三次失败退回 2。
- 对受影响的第 3 版规则后续局存档，只有唯一计数组合能通过完整严格重放和快照校验时才修复；修复前保留原始 JSON 备份，再增加修订号。无法验证的损坏仍拒绝恢复。
- 存档格式继续为 4.0，历史规则 1/2 保留原有语义。

## GUI/TUI 响应与可靠性

- 存档列表、读取、恢复副本、历史、回放验证、新局覆盖检查转入后台，慢存储期间仍能返回。
- 两端共用思考、保存、失败和离开状态，保存重试不重复出牌；隐藏或离开页面后丢弃过时完成结果，关闭时安全处理后台回调。

## AI 与研究工具

- 搜索、残局、细化和参考续局共用绝对决策预算；类型化配置保留已有构造参数及兼容属性。公开观测统一限制战术、搭档建模和排序的信息来源。
- 默认五档编号与策略保持兼容，职业常规/关键预算为 1/2 秒，戴长胜为 2/5 秒。30 个固定局面的动作、原因及随机流与隔离旧策略一致。
- 研究进程共用带启动/请求时限的 RPC，保留失败请求与 stderr；依赖 manifest 覆盖引擎、序列化、策略、脚本、夹具和锁文件。历史 worker 使用版本化冻结夹具，可在干净 CI 中运行。
- 保留搭档、动作排序、续局、预算细化与紧急拦截研究及失败证据。单项续局诊断提高了模拟完成比例，却未稳定改善动作损失，**研究开关继续默认关闭**；代理估值与小样本诊断不能解释为真人胜率提升。

## 验证与证据

- 发布前本地 1,052 项测试通过，无跳过；分支综合覆盖率 85.03%。Ruff、mypy 及存储、共享会话、重放覆盖率门槛通过。
- 固定回归 30/30、隔离旧策略对照 30/30、串行生产预算检查 42/42 通过；一场比赛共 8 小局严格事件重放通过，30 个 GUI/TUI 视觉状态通过。
- 实际前端连续三家行动与保存的单局面测量：职业 GUI/TUI 为 5.15/3.63 秒，戴长胜为 8.02/6.59 秒，含界面展示停留。测量使用 offscreen/headless 环境，不代表所有牌局和桌面性能。
- 发布流程对同一标签 SHA 执行 Python 3.10/3.12 质量检查、研究测试、固定决策门禁、三个平台视觉冒烟和四种桌面构建。运行结果见 [GitHub Actions](https://github.com/itsVicOC/guandan/actions)。

详见 [审查落地报告](https://github.com/itsVicOC/guandan/blob/v0.8.7-beta.1/OPTIMIZATION-2026-10-09.md)与 [验收记录](https://github.com/itsVicOC/guandan/blob/v0.8.7-beta.1/benchmarks/README.md)。研究附件 `research-20261009.zip` 保留 892 个原始文件及逐文件 SHA-256 索引；原始记录仍保留在源码仓库。

## 下载

桌面包包含 Python、PySide6 和运行依赖，解压后即可运行：

| 文件 | 平台 / 用途 |
| --- | --- |
| `Guandan-v0.8.7-beta.1-windows-x64.zip` | Windows x64，运行 `Guandan/Guandan.exe` |
| `Guandan-v0.8.7-beta.1-linux-x64.tar.gz` | Linux x64，运行 `Guandan/Guandan` |
| `Guandan-v0.8.7-beta.1-macos-x64.zip` | Intel Mac，打开 `Guandan.app` |
| `Guandan-v0.8.7-beta.1-macos-arm64.zip` | Apple Silicon Mac，打开 `Guandan.app` |
| `guandan-0.8.7b1-py3-none-any.whl` | Python 包，桌面 GUI 需额外安装 `gui` 依赖 |
| `research-20261009.zip` | 研究原始记录与校验索引 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值 |

公测桌面包未进行商业代码签名或 Apple 公证，首次启动时操作系统可能要求确认。macOS 可在 Finder 中右键应用并选择「打开」。
