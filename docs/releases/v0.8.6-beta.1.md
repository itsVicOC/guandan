# v0.8.6-beta.1 公测版 Release Notes

发布日期：2026-09-30

本版修正三次冲 A 规则和 AI 整场估值，加强限时残局搜索的可靠性。Python 包版本为 `0.8.6b1`，支持 Python 3.10+；五档难度编号与现有思考预算保持不变。

## 三次冲 A 与存档兼容

- 新开比赛使用第 3 版规则：每队累计三次冲 A 失败后退回 2；前两次失败保留 A，双方分别计数。获得头游且队友不是末游才算成功过 A，结束整场比赛。
- 失败次数进入存档、下一局状态和事件重放，GUI/TUI 显示相同结算结果。
- 旧规则版本 1/2 的存档和回放继续使用原有规则，不改写历史比赛；存档格式继续为 4.0。

## 默认 AI 修正

- 整场估值计入双方级别、各自冲 A 失败次数、队友名次及贡还牌条件。真正过 A 按本方收益 1、对方收益 0 处理，普通小局与冲 A 失败使用后继比赛状态估计，区分首次失败与第三次退回 2。
- 统一公开过牌软证据，忽略队友礼让并去除同墩相关重复证据；不会把一次过牌解释为没有该牌，也不读取真实暗牌或发牌种子。
- 修正搜索换牌门槛，保留配对误差要求。小残局实体枚举覆盖花色与逢人配变体，缓存区分精确值、上界和下界；搜索未到终局、枚举未完成或预算耗尽时明确回退。
- 保持全场不超过 12 张的小残局入口、70% 残局时间额度和 30,000 节点上限。职业仍为常规 1 秒、关键 2 秒，戴长胜仍为常规 2 秒、关键 5 秒；新手、进阶定位不变。
- 修复 TUI 退出后 AI 回调访问已卸载控件的问题。

## 协作实验的结果与默认配置

实现队友接管、夺权后领出回应链、异质队友续局及八世界残局实验，并冻结完整旧策略作为隔离对照。真人回放仅固定公开前缀，分支后使用合法代理续局。

冻结候选在一次性 240 对整队代理评测中，团队收益差为 +0.0596，95% 配对区间为 [+0.0276, +0.0930]；另一次性 60 对不同风格队友评测为 -0.0038，区间为 [-0.0672, +0.0579]，未证实改善。因此协作与搜索实验开关保持默认关闭，不把实验结果归为默认策略的收益提升。

**整场继续值来自离线代理模型，不是实际真人搭档胜率。**本版默认启用规则、估值目标、过牌证据、统计门槛及搜索可靠性修正；全部在本地运行，没有在线模型或大规模强化学习训练。详细实现、局限、源码指纹与复现命令见 [完整报告](https://github.com/itsVicOC/guandan/blob/v0.8.6-beta.1/docs/ai-comprehensive-optimization.md)。

## 验证

- 785 项自动化测试通过，行/分支综合覆盖率 84.44%；Ruff、mypy 和存储、共享 session、重放模块覆盖率门槛通过。
- 30 次固定工作量决策匹配更新后的 v6 回归基线，动作变化已复核。
- 60 次串行时钟检查全部通过，分别覆盖最终默认配置、冻结候选及冷缓存残局。
- 4 对完整比赛共 8 场、93 小局，全部结束且逐局严格重放一致，覆盖第三次冲 A 失败退回 2。该小样本只验证完整流程。
- 跨平台质量检查、视觉冒烟和桌面构建须通过同一标签 SHA 的发布门禁，结果见 [GitHub Actions](https://github.com/itsVicOC/guandan/actions)。原始记录见 [benchmarks/README.md](https://github.com/itsVicOC/guandan/blob/v0.8.6-beta.1/benchmarks/README.md)。

## 下载

桌面包包含 Python、PySide6 和运行依赖，解压后即可运行：

| 文件 | 平台 / 用途 |
| --- | --- |
| `Guandan-v0.8.6-beta.1-windows-x64.zip` | Windows x64，运行 `Guandan/Guandan.exe` |
| `Guandan-v0.8.6-beta.1-linux-x64.tar.gz` | Linux x64，运行 `Guandan/Guandan` |
| `Guandan-v0.8.6-beta.1-macos-x64.zip` | Intel Mac，打开 `Guandan.app` |
| `Guandan-v0.8.6-beta.1-macos-arm64.zip` | Apple Silicon Mac，打开 `Guandan.app` |
| `guandan-0.8.6b1-py3-none-any.whl` | Python 包，桌面 GUI 需额外安装 `gui` 依赖 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值 |

公测桌面包未进行商业代码签名或 Apple 公证，首次启动时操作系统可能要求确认。macOS 可在 Finder 中右键应用并选择「打开」。
