# v0.8.1-beta.2 公测版 Release Notes

发布日期：2026-09-16

## 发布定位

`v0.8.1-beta.2` 聚焦实战牌桌的过程可读性：AI 行动逐手展示，结束牌墩不会瞬间消失，并通过牌墩阶段、收牌结果和最近行动轨迹完整呈现牌局推进。

Python 包版本为 `0.8.1b2`。

## 主要更新

### 逐手呈现牌局

- AI 每次只执行一手公开行动，界面在下一位 AI 行动前保留清晰的阅读时间。
- 连续 AI 出牌或过牌不再直接跳到真人回合，玩家可以按顺序看到每家选择。
- 牌桌保留最新 5 次公开行动，并展示本局累计公开行动数。

### 清晰的收牌阶段

- 一个牌墩结束后，获胜牌和最终过牌仍会保留在桌面，直到下一手牌实际打出。
- 新增“等待”“进行中”“已收牌”阶段标识，并明确提示收牌玩家、下一手先手或接风玩家。
- 当前最大牌所在行使用暖金高亮，当前行动方使用青色边缘提示。
- 放大牌墩缩略牌及点数、花色，最低 `1080×760` 窗口下仍可完整查看四家状态、桌面和手牌。

### 兼容性与验证

- 牌墩保留策略仅用于桌面 GUI，终端 TUI 保持既有紧凑清理行为。
- 新增进行中牌墩和已收牌牌墩的视觉回归截图。
- 429 项自动化测试、Ruff、完整 GUI/TUI 视觉验收和差异检查通过。

## 桌面下载

- `Guandan-v0.8.1-beta.2-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.1-beta.2-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.1-beta.2-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.1-beta.2-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.1b2-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。

Windows、Linux、macOS Intel 与 macOS Apple Silicon 安装包由标签发布工作流分别原生构建和验证；全部构建成功后 GitHub Release 会自动发布。
