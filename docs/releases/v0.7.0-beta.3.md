# v0.7.0-beta.3 公测版 Release Notes

发布日期：2026-06-16

## 发布定位

`v0.7.0-beta.3` 是公测阶段的 M7 AI 调优收口版本，重点完成 AI 对战基准、MCTS 搜索性能与评分、高手/职业/戴长胜档残局策略和短手牌拦截的系统性优化。

Python 包版本为 `0.7.0b3`。

## 主要更新

- 新增 AI benchmark JSON 输出、结果对比和回归门禁，便于后续保存调参基线。
- 抽取当前牌墩 helper，统一状态机、AI 和 TUI 对当前桌面出牌者、最大牌玩家和锁定过牌玩家的判断。
- 优化 MCTS rollout 评分、轻量模拟、默认预算和候选剪枝，减少职业档等待并保留终局动作。
- 进阶及以上 AI 更主动领出自然顺子、连对、钢板和三带二，减少无效单牌消耗。
- 对手报单或短手牌时，AI 更稳定地拦截，不再被随机过牌、队友协作或戴长胜配合意识误覆盖。
- 修正记牌器双副牌点数总数，避免高手策略误判绝张。
- 戴长胜档补强终局牌优先、必用炸弹优先、炸弹吝啬和漂牌保护之间的优先级。

## M7 基准

收口基准命令：

```bash
python -m guandan.ai.benchmark --games 20 --difficulties 0,1,2,3 --seed-start 800 --max-turns 2000 --json
```

结果摘要：

- 20/20 完成，完成率 1.0。
- 平均 91.15 回合。
- 平均炸弹数 `[0.3, 0.4]`。
- 胜场 `[2, 18]`；这是混合难度座位基准，1/3 号位难度整体高于 0/2 号位，不作为公平胜率结论。
