# v0.8.0-beta.4 公测版 Release Notes

发布日期：2026-07-27

## 发布定位

`v0.8.0-beta.4` 完成跨局交互、持久化可靠性和高档 AI 的系统性升级，并继续提供 Windows、macOS 与 Linux 可直接运行的桌面包。

Python 包版本为 `0.8.0b4`。

## 主要更新

### 牌局与交互

- 新增比赛级 `match_id` 与小局序号，历史、存档和统计能够正确区分整场比赛与每一小局。
- 真人可交互选择合法贡牌与还贡牌；下一局完整承接升级、进贡、还贡、抗贡和先手规则。
- GUI/TUI 的 AI 决策移到后台执行，思考期间界面保持响应，并保护保存、退出和自动存档流程。
- 新增存档覆盖与删除确认、异常提示、报单/报双状态，以及 GUI/TUI 牌桌式逐步回放和自动播放。

### AI

- 职业与戴长胜档升级为团队感知 SO-ISMCTS：每次模拟重新采样隐藏牌，队友最大化根队收益，对手执行对抗选择。
- 隐藏牌采样严格隔离对手真实手牌，并将贡还牌作为硬约束、过牌行为作为非零软证据。
- 搜索加入分层候选、availability、渐进扩展、结构化 rollout，以及升级、冲 A、控场和剩余牌力估值。
- 戴长胜风格参数由确定性镜像自对弈筛选；40 局生产留出对职业档为 `21/40`，平均升级差 `+0.40`，决策 p95 为 `0.429s`。
- 新增镜像 Arena、整场过 A 模式、Wilson 区间、Elo、延迟指标、自对弈调参器和夜间 AI 回归工作流。

### 可靠性与验证

- Profile、存档和历史写入增加跨进程文件锁，GUI/TUI 并行运行时避免写入损坏和统计丢失。
- Profile 与存档升级到 3.0，并保留旧数据迁移；历史损坏条目不再挤占可用记录。
- 新增仓库内 GUI/TUI 视觉验收脚本，CI 在 Linux、Windows 和 macOS 生成并上传验收产物。
- 418 项自动化测试通过，Ruff、mypy、锁文件与差异检查全部通过。

## 桌面下载

- `Guandan-v0.8.0-beta.4-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.0-beta.4-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.4-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.4-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.0b4-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。

## 验证

- Python 3.10 / 3.12 全量测试。
- Ruff、mypy 和 compileall 静态验证。
- Windows、macOS Intel、macOS Apple Silicon 与 Linux 分别原生构建。
- 每个平台在归档前启动打包后的可执行程序进行 smoke test。
