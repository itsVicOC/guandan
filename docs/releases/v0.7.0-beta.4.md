# v0.7.0-beta.4 公测版 Release Notes

发布日期：2026-06-18

## 发布定位

`v0.7.0-beta.4` 是公测阶段的规则细节与 TUI 体验补丁版本，重点校准同花顺 / 炸弹层级、还贡边界、报牌入口、规则文档表述，以及开局后手牌显示不全的问题。

Python 包版本为 `0.7.0b4`。

## 主要更新

- 修正同花顺 / 普通炸弹比较：同花顺可压 4/5 张普通炸弹，6 张及以上普通炸弹可反压同花顺。
- AI 炸弹排序同步真实炸弹层级，避免策略错误评估同花顺和 6+ 普通炸弹的消耗顺序。
- 炸弹统计口径统一为普通炸弹、同花顺和四王炸都会计入 `team_bomb_count`。
- 还贡牌选择在极端无合法还贡牌状态下显式报错，不再退回非法牌。
- 手动报牌入口收紧为自动报牌兼容补报：10 张以上不能记录报牌，同一玩家同一张数不会重复记录。
- TUI 启动时会尽力请求终端调整到 `140x48` 推荐尺寸，并在牌局页按实际窗口宽度动态调整每行手牌数量，减少开局 27 张手牌被挤出可视区域。
- 自动调整会避开 CI / tmux / screen / SSH / 非 TTY 等受管理终端环境，也可通过 `GUANDAN_TUI_NO_RESIZE=1` 禁用。
- 修复牌局页按钮获得焦点后，选牌按回车会误触发“返回大厅”而不是出牌的问题。
- README、规则文档、CHANGELOG 同步过 A “双上条件”和同花顺 / 炸弹层级口径。
