# v0.8.5-beta.1 公测版 Release Notes

发布日期：2026-09-27

本版完善四人牌桌、智能理牌和存档恢复，并重新整理带有实际游戏截图的 README。Python 包版本为 `0.8.5b1`，继续支持 Python 3.10+；AI 默认策略、难度编号与思考预算保持不变。

## 游戏界面与上手说明

- 四家最近出牌按座位展示，当前最大牌与正在行动的玩家分别标示；本墩记录保留到下一墩首出，读档后也能重建桌面。
- 最近行动收纳到桌角，贡还信息移到顶部状态区。
- GUI / TUI 首次理牌在有可用同花顺时优先展示同花顺方案，比较重叠组合和逢人配分配；手工锁定组不参与重排。
- [README](https://github.com/itsVicOC/guandan/blob/v0.8.5-beta.1/README.md) 加入四人牌桌、大厅、回放和终端界面截图，以及下载步骤、首次开局流程、快捷键对照和五档 AI 说明。

## 存档与交互可靠性

- 下一局发牌展示、待进贡和待还贡阶段可以保存，重启后恢复原阶段。
- 使用存档归属和修订号检查阻止旧进度覆盖；冲突进度保存在数据目录的 `recovery/` 中，可从续局页面恢复，恢复前先备份当前存档。
- AI 搜索或后台写盘失败后暂停后续行动，支持显式重试；写盘重试不会重复执行已完成的出牌。
- 关闭窗口、返回大厅和 TUI 退出会等待当前 AI 行动并在后台保存。
- 修复损坏或缺失的统计字段，保留原始备份；提供 `python -m guandan.storage.maintenance` 预览历史统计重建，添加 `--apply` 后应用并备份。
- CLI 查询和无效输入不再消耗对局动作上限，支持退出和 EOF。

**存档兼容：**本版写入 **4.0** 格式，可以读取并迁移 1.0–3.0。旧版本不能读取 4.0 存档，回退程序前请备份数据目录。默认目录为 `~/.guandan/`，也可通过 `GUANDAN_DATA_DIR` 指定。

## 工程与验证

- 分离 GUI 牌桌、回放、通用控件与后台任务，共享 GUI / TUI 异常处理语义。
- CI 锁定依赖，运行 Python 3.10 / 3.12 质量检查和三个桌面平台的视觉冒烟；桌面构建与发布必须等待同一标签 SHA 的质量检查通过。
- 增加固定工作量 AI 回归、生产时钟检查和搜索诊断。预算实验只作为诊断记录，本版不新增棋力提升结论。
- 本地 macOS / Python 3.10 验证：**581 项测试通过**，行 / 分支综合覆盖率 **85.10%**；Ruff、mypy、关键模块覆盖率门槛和锁文件检查通过。
- 固定工作量回归的 **30 / 30** 决策通过；新手完整比赛成功过 A，每小局事件重放均无漂移；30 个 GUI / TUI 视觉验收产物检查通过。
- 跨平台质量检查与构建结果见该标签对应的 [GitHub Actions](https://github.com/itsVicOC/guandan/actions)，详细评测口径见 [benchmarks/README.md](https://github.com/itsVicOC/guandan/blob/v0.8.5-beta.1/benchmarks/README.md)。

## 下载

桌面包包含 Python、PySide6 与运行依赖，解压后即可运行。请按处理器架构选择文件：

| 文件 | 平台 / 用途 |
| --- | --- |
| `Guandan-v0.8.5-beta.1-windows-x64.zip` | Windows x64，运行 `Guandan/Guandan.exe` |
| `Guandan-v0.8.5-beta.1-linux-x64.tar.gz` | Linux x64，运行 `Guandan/Guandan` |
| `Guandan-v0.8.5-beta.1-macos-x64.zip` | Intel Mac，打开 `Guandan.app` |
| `Guandan-v0.8.5-beta.1-macos-arm64.zip` | Apple Silicon Mac，打开 `Guandan.app` |
| `guandan-0.8.5b1-py3-none-any.whl` | Python 包，桌面 GUI 需要额外安装 `gui` 依赖 |
| `SHA256SUMS.txt` | 发布文件的 SHA-256 校验值 |

公测桌面包未进行商业代码签名或 Apple 公证，首次启动时操作系统可能要求确认。macOS 可在 Finder 中右键应用并选择「打开」。
