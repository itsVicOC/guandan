# v0.8.2-beta.2 公测版 Release Notes

发布日期：2026-09-23

本版重点改善每一小局的开始、贡还牌、出牌和结算反馈，同时保留并验证上一版的高档 AI 配对根动作评估。Python 包版本为 `0.8.2b2`。

## 牌局交互

- GUI 和 TUI 在开局、进行中、结束时明确显示本局级牌。中央牌桌持续显示进贡、还贡或抗贡结果；即使玩家未参与，也会看到完整公开信息。
- 最小 `1080×760` 窗口下，GUI 的南家行动行和最近行动区不再被手牌区遮挡。
- GUI 操作按钮按当前阶段显示；选牌时即时预览牌型及能否压过桌面。贡还牌直接在手牌中选择合法牌并确认。
- 结算区展示四家名次、两队级牌变化和下一局入口。AI 思考状态、行动高亮与“回看上一墩”让出牌过程更容易追踪。

## AI 与评估

- 根动作评估使用轻量状态克隆；固定种子的搜索统计与原深拷贝实现一致。
- 新增全部合法动作的候选召回审计，以及跨级牌、座位和来源策略的留出评估。现有样本未证明将 root32 预算提高到 root96 有稳定棋力收益，生产策略维持原预算。
- 复杂牌型定向 rollout 实验未优于当前轻量策略，仅作为可复现对照保留。
- 最高档的说明与实际实现对齐为更高预算的团队根动作评估，移除未生效的过牌倍率配置。

## 验证

- 20 局混合难度基准全部完成；平均回合 `91.1`，两队平均炸弹数 `[0.95, 1.15]`，与上一版基准一致。
- 479 项自动化测试、GUI/TUI 视觉截图、Ruff 和 mypy 通过；各平台桌面包由标签发布工作流分别构建并进行 smoke test。
