# v0.8.0-beta.3 公测版 Release Notes

发布日期：2026-07-24

## 发布定位

`v0.8.0-beta.3` 修复出牌提示候选遗漏，并首次提供 Windows、macOS 和 Linux 可直接运行的桌面包。

Python 包版本为 `0.8.0b3`。

## 主要更新

- “提示”会直接选中一组能够压过桌面牌型的手牌，连续点击可遍历全部不同合法方案并循环返回第一组。
- 无牌可压时明确建议过牌；用户手动改变选择后，提示循环会重新开始。
- 修复手牌中另有王时，普通炸弹、顺子、连对和钢板从提示及 AI 候选中消失的问题。
- 普通压牌方案优先展示，炸弹方案随后展示；提示牌型与实际点击“出牌”后的识别结果保持一致。
- GUI 与 TUI 共享相同的提示候选和选牌映射逻辑。

## 桌面下载

- `Guandan-v0.8.0-beta.3-windows-x64.zip`：Windows 10/11 x64，解压后运行 `Guandan/Guandan.exe`。
- `Guandan-v0.8.0-beta.3-macos-arm64.zip`：Apple Silicon Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.3-macos-x64.zip`：Intel Mac，解压后打开 `Guandan.app`。
- `Guandan-v0.8.0-beta.3-linux-x64.tar.gz`：Linux x64，解压后运行 `Guandan/Guandan`。
- `guandan-0.8.0b3-py3-none-any.whl`：供 Python 环境安装。
- `SHA256SUMS.txt`：所有发布资产的 SHA-256 校验值。

桌面包已包含 Python、PySide6 和运行依赖。当前公测包未进行代码签名，Windows SmartScreen 或 macOS Gatekeeper 首次启动时可能显示安全确认。

## 验证

- Python 3.10 / 3.12 全量测试。
- Ruff、mypy 和 compileall 静态验证。
- Windows、macOS 与 Linux 分别原生构建。
- 每个平台在归档前启动打包后的可执行程序进行 smoke test。
