# v0.8.3-beta.1 公测版 Release Notes

发布日期：2026-09-24

本版改进 GUI 与 TUI 的智能理牌，并修正新牌局的过牌作用范围。Python 包版本为 `0.8.3b1`。

## 智能理牌

- 牌局中可循环查看综合牌型、各牌型优先、点数、花色和张数理牌方案；AI 行动时也可理牌，出牌规则与实际手牌不变。
- 综合方案优先保留并前置四王炸、炸弹和同花顺。牌组紧叠展示，以组间留白区分，不再在牌面上常驻显示牌型标签。
- GUI 可从菜单直接选择方案并双击选中整组；TUI 可用 `S` 切换方案、`G` 选中整组。重排后保留已选牌，TUI 光标跟随原牌。

## 出牌规则与兼容性

- 过牌只回应当前桌顶；有人压牌后，仍在场的玩家重新获得跟牌机会。当前最大牌之后的其他玩家都过牌才收墩。
- 新牌局使用修正后的规则。旧存档与历史按原规则重放，继续支持续局与回看。

## 验证

- 495 项自动化测试、Ruff、mypy 和 GUI/TUI 理牌布局检查通过。
- Windows x64、Linux x64、macOS Intel 与 Apple Silicon 桌面包由标签发布工作流构建并进行启动检查，全部成功后附到本 Release。
