# v0.8.2-beta.1 公测版 Release Notes

发布日期：2026-09-21

## 发布定位

`v0.8.2-beta.1` 聚焦高档 AI 的出牌质量与评估可信度：用配对根动作评估取代低预算下收益不足的默认树搜索，并建立可复用的 200 局面高精度动作价值基线。

Python 包版本为 `0.8.2b1`。

## 主要更新

### 配对根动作评估

- 每轮只采样一个与玩家公开信息一致的隐藏世界，所有候选动作在该世界的独立副本上进行 rollout，直接形成配对比较。
- 候选池最多保留 6 个分层搜索动作，并显式覆盖合法过牌和 greedy 实际动作。
- 职业档使用最多 32 次评估或 240ms；戴长胜使用最多 96 次评估或 420ms。
- 生产采用轻量 rollout 和均匀预算分配；实验中逐步淘汰候选的 racing 方案表现更差，未被采用。
- 旧团队感知 SO-ISMCTS 仍可通过 `search_mode="tree"` 启用，便于回归和研究。

### 可复用的动作价值基线

- 基线覆盖 200 个中残局面、1,137 个动作，每个动作使用 400 次固定种子出牌估值。
- JSON 结果包含逐局面 regret、方法置信区间、配对差值置信区间、t 值和耗时，可直接用于后续算法比较。
- 原搜索测量确认：search64 显著优于 greedy，但 search32/search64 均未显著优于 argmax32。
- 新生产 root96 的 regret 为 `0.0424`（95% CI `0.0347–0.0501`），相对旧 search64 显著降低 `0.0125`（`t=-2.48`）；相对 argmax32 的差异不显著。

### 整局验证与兼容性

- 固定迭代、交换座位的 16 局 Arena 中，root32 对旧 tree64 为 `8:8`，平均升级差 `0.00`。
- 生产时钟口径的 8 局 Arena 同样为 `4:4`；root32 决策平均约 105ms、p95 约 247ms。
- 以上 Arena 是小样本非回退证据，不宣称整局胜率显著提升。
- 473 项自动化测试、Ruff、mypy、基准 JSON 完整性和差异检查通过。
- 20 局混合难度基准完成率为 100%，炸弹均值相对上一基线漂移 `0.00/+0.15`，通过 CI 门禁。
