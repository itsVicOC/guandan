# 掼蛋规则详解

> 本文档详细说明掼蛋游戏规则，与全国锦标赛通用口径一致。

## 1. 游戏概述

掼蛋（Guandan）是一种流行的扑克牌游戏，起源于江苏淮安，是"跑得快"和"八十分"的结合体。4人游戏，2人一队，以先"过A"（打完A级）的队伍获胜。

### 基本信息

- **牌数**：2副扑克共108张（52×2 + 4张王）
- **人数**：4人，固定搭档（东↔西 / 南↔北 为同队）
- **座位与出牌方向**：座位编号为东=0、南=1、西=2、北=3；出牌按逆时针顺序：东 → 北 → 西 → 南 → 东
- **目标**：从2级开始，逐级升级，先打过A级的队伍获胜

## 2. 基本规则

### 2.1 级牌制度

- 每局有一个**级牌**（2～A），由当前打到的级别决定
- 级牌是本局最大的非王牌，可以单出
- 2是所有非级牌中最小的点数
- A是最高级别，打过A即冠军

### 2.2 发牌

- 每人发27张牌，无底牌
- 发牌前需要洗牌

### 2.3 逢人配（万能牌）

- **红心级牌**是本局的万能牌（joker）
- 逢人配可以替代任何牌，用于组成牌型
- 例：当前级牌是5，则红心5为逢人配

## 3. 牌型说明

### 3.1 基础牌型

| 牌型 | 说明 | 示例 |
| --- | --- | --- |
| **单张** | 1张牌 | 3 |
| **对子** | 2张相同点数的牌 | 77 |
| **三张** | 3张相同点数的牌 | 888 |
| **三带二** | 3张+2张（类似葫芦） | 888+99 |

### 3.2 连牌牌型

| 牌型 | 说明 | 最短长度 |
| --- | --- | --- |
| **顺子** | 连续的单牌 | 5张起 |
| **连对** | 连续的对子 | 3对起 |
| **钢板** | 连续的三张 | 2组起 |

**顺子特殊规则：**
- A可以在顺子中**双向**使用：
  - 作为最大：10-J-Q-K-A
  - 作为最小：A-2-3-4-5
- 但不能跨越：K-A-2-3-4（非法）

### 3.3 炸弹牌型

炸弹是特殊牌型，可以压任何非炸弹牌型。当前实现中炸弹只影响牌力和战术节奏，不直接增加升级数。

| 炸弹类型 | 说明 | 示例 |
| --- | --- | --- |
| **4张炸弹** | 4张相同点数 | 6666 |
| **5张炸弹** | 5张相同点数 | 77777 |
| **6张炸弹** | 6张相同点数 | 888888 |
| **7张炸弹** | 7张相同点数 | 9999999 |
| **8张炸弹** | 8张相同点数 | 10-10-10-10-10-10-10-10 |
| **同花顺** | 同花色顺子（5张起） | ♠5-6-7-8-9 |
| **四王炸** | 2张大王+2张小王 | 👑👑🃏🃏 |

**炸弹大小顺序：**
1. 四王炸 > 同花顺 > 8张炸 > 7张炸 > ... > 4张炸
2. 同类炸弹，点数大的更大
3. 同花顺之间，长度优先，长度相同则点数大的更大

## 4. 出牌规则

### 4.1 首轮出牌

- 第一局由随机玩家先手
- 后续各局由上局的**头游**（第一名）先手

### 4.2 跟牌规则

- 必须出**相同牌型**且**能压过桌面**的牌
- 如无法压牌或不想出，可选择**过牌**
- 出牌顺序为**逆时针**：东 → 北 → 西 → 南 → 东

### 4.3 过牌规则

- 一旦选择"过"，该玩家在**本圈牌**中将失去出牌机会
- 当所有非当前最大牌玩家都过牌后，本圈结束
- 最后出牌者获得下一轮的领出权

### 4.4 接风（借风）规则

当玩家出完最后一手牌后：
- 如果**无人压牌**（其他所有人都过牌），则其**对家**接风，成为下一轮先手
- 如果有人压牌，则由压牌者继续领出（不接风）

## 5. 升级规则

### 5.1 名次判定

- **头游**：第1个出完手牌的玩家
- **二游**：第2个出完手牌的玩家
- **三游**：第3个出完手牌的玩家（手牌较少者）
- **末游**：最后剩余的玩家

游戏在**三游产生**时结束（不必等末游出完）。

### 5.2 升级计算

**只有头游所在队伍升级**，对方不降级。升级公式：

```
升级数 = 基础升级 + 炸弹加成
```

**基础升级：**
- **双下**（头游+二游）：+3级
- **头游+三游**：+2级
- **头游+末游**：+1级

**炸弹说明：**
- 当前实现采用“炸弹不参与升级”的口径。
- 头游方升级只由名次组合决定，漂牌另加 +3。

### 5.3 漂牌规则

如果头游方的**最后一手**满足：
- 是5张或以上的牌
- 包含级牌炸弹（4张及以上级牌）

则下局**再额外+3级**（漂牌奖励）。

## 6. 特殊规则

### 6.1 进贡 / 还贡 / 抗贡

**进贡：**
- 非首局开始前，**末游**向**对方头游**进贡最大的1张牌

**还贡：**
- 收到贡牌的头游，向进贡者还任意1张牌

**抗贡：**
- 末游持有**2张大王+2张小王**可抗贡
- 抗贡成功则不进贡，不还贡

### 6.2 过A规则

当一队打到A级时，必须满足**双下条件**才能过A：
- 头游 + 二游（双下）✓
- 头游 + 三游 ✓
- 头游 + 末游 ✗ **冲A失败**

**冲A失败：**
- 头游方降回2级
- 对方不升级

**过A成功：**
- 该队获胜，游戏结束

### 6.3 报牌规则

- 当手牌数 ≤ 10张时，系统自动提示剩余张数
- 其他玩家可据此判断形势

## 7. 胜负判定

- **冠军条件**：先打过A级的队伍
- 过A需满足双下条件（头游+队友非末游）
- 冲A失败则降回2级，对方不受影响

## 8. 游戏策略提示

### 8.1 配合意识

- 对家是队友，应协作而非竞争
- 队友领先时可适当过牌，让队友先走
- 记住已出的牌，判断对手可能的牌型

### 8.2 炸弹使用

- 炸弹是强力牌型，可用于控场、拦截和保护队友
- 当前实现中炸弹不会增加升级数，使用时机主要看牌权和剩余手牌
- 戴长胜风格：炸弹吝啬，控场为先

### 8.3 漂牌决策

- 最后一手能打5张+级牌炸弹可漂牌
- 漂牌额外+3级，但需要保留特定牌型
- 权衡是否值得为漂牌调整出牌策略
