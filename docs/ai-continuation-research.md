# 续局一致性与手牌规划研究（v9～v11）

本轮继续分析 v8 动作排序未改善对赛的原因。对照为当前工作区默认策略的完整快照，所有 v7/v8 研究开关关闭；不使用 v8 已保留的独立验收种子。

## 探索性动作诊断

复用 v8 动作诊断前 32 副牌，每副一处公开局面，均衡轮换阶段。每次决策固定 128 次动作评估，两档及各方法使用相同根随机流。标签是原有三种搭档、32 个世界的完整高手续局收益。这些标签此前已经观察过，**只能用于探索和解释，不能作为新独立验收**。动作 regret 只相对于已标注动作池；表内最终选牌全部可在标签中找到。

| 方案 | 职业最终 regret | 戴长胜最终 regret | 相对默认选牌变化（3 / 4） |
| --- | ---: | ---: | ---: |
| 默认 | 0.018940 | 0.019036 | 0 / 0 |
| v8 模型提名 | 0.018940 | 0.019036 | 0 / 0 |
| 轻量续局延长至 120 步 | 0.018577 | 0.019776 | 3 / 5 |
| 轻量续局至完整结算（上限 4000） | 0.018577 | 0.019776 | 3 / 5 |
| 前八步高手，其后轻量续局至 120 步 | 0.013593 | 0.013707 | 4 / 6 |
| 完整高手续局 | 0.016222 | 0.017478 | 6 / 6 |
| 两阶段高手复核 | 0.010949 | 0.016497 | 2 / 2 |

默认候选池内的最低 regret 为职业 0.003710、戴长胜 0.002520。模型在职业补入五次、最高档一次，均没有改变最终动作。默认模拟只有约 35% 完成名次、49% / 53% 已确定头游；120 步轻量续局在本批样本中全部完成。单纯延长模拟没有同时改善两档，候选覆盖也不是这批样本的主要损失。收益保护确实阻挡部分低质量搜索偏离：原始搜索最佳动作的标签 regret 与最终选牌 regret 单独保留，不能将“改变更少”解释为棋力退化。

高手续局与标签策略更接近，但它的诊断改善包含策略对齐、截断减少及采样误差，不能单独归因于某一项，也不能将完整高手续局视为真值。旧样本中的两阶段 regret 降幅约 42.2% / 13.3%，需由新对赛检验。

原始记录及当时的脚本保存在 `benchmarks/continuation-v9/exploratory*.json`、`*-recipe.py`。探索阶段计时使用八个进程，且不同方法按固定顺序运行，受到 CPU 竞争及缓存影响；不使用这些时间作串行性能结论。

## 两阶段高手复核

`reference_refinement` 是职业与戴长胜的默认关闭研究参数：

1. 用一半现有工作量和至多一半根时钟执行原轻量搜索，保留原候选及弱先验。
2. 若最佳动作与战术参考相同，直接结束；否则仅对该挑战动作与战术参考进行第二阶段。
3. 第二阶段使用新的共同暗牌世界，前八次行动执行默认高手策略，其后沿用原轻量策略，最多 120 步。只使用这两臂新的配对样本估值，不混合第一阶段的不同策略估值。
4. 至少六个完整共同世界才可提出偏离，否则回退战术参考；最终仍经过原置信度、收益、过牌和炸弹保护。

两阶段合计不超过原 256/768 次评估及原根预算。职业保持 1/2 秒，最高档保持 2/5 秒；前三档、规则、存档、五档编号、`select_pattern` 和最高档原残局路径不变。没有启用 v8 模型、风格适配或回应链。

`reference_rollout_turns` 单独保留全池高手续局研究接口，默认 0。其决策缓存局限于一次搜索，只包含当前行动者自身实体手牌、公开张数、桌顶/牌权、过牌锁、名次和已出点数。禁止与风格适配组合。缓存前后完整行动轨迹和值逐项相等；替换真实暗牌和私有发牌种子后专家选择及根评分不变。

对照快照 `baseline-snapshot.zip` 指纹为 `4834f59bdf4d0553131e2fbb9e26fa135ff2cff4e9b368031b308bb61b05d40a`。冻结候选、脚本及配置见 `candidate-snapshot.zip`，实验指纹为 `3bc1c64dc69c1c69acd649477d66d833927478b8d1b5769a74879ca1e8e1bebd`。对照从独立进程导入冻结源码；请求剥离其他真实手牌与私有发牌种子。

预定开发比较 `horizon120` 与 `refined`，两档各整队 32 对、混合搭档 32 对，固定 128 次工作量，共 256 对、512 个完整小局。两个方案共用开发牌局，按整队和混合平均配对收益较小值选择；只有两项均为正且该档串行时钟通过，才进入独立验收。

候选验收每档固定整队 240 对、混合 240 对（256/768 次评估），另做 48 对实际完整比赛。新种子按 `continuation-v9/阶段/比赛编号/局号` 派生，与 v8 及其他阶段不重叠。比赛各腿保留相同初始分数、A 失败次数、先手和牌局，只交换策略座位。正式验收要求两个 95% 配对区间下界均大于零、三个搭档均非负、实际完整比赛胜率区间下界大于 50%，并通过合法性、严格重放、真人公开前缀分支和串行时钟检查。验收后不追加样本寻找通过结果。

两种方案的冷/热缓存和三家连续行动共 84 次串行检查全部通过 `1.15 × 当次预算 + 100ms`。高手复核在部分开局中仅取得 0～2 对完整样本，因此触发回退；满足时限不意味着已获得足够复核信息。时钟记录显式保留各阶段样本和回退原因。

## 计数器开销与整数多重集合原型

一次开局高手前八步续局的剖析中，约 93% 的累计时间进入手牌规划；主要开销是对子集选项反复构造 `Counter`、相减、排序剩余牌。剖析是单例、带探针的归因数据，不作总体速度结论。

研究原型 `scripts/ai_hand_plan_bitmask.py` 为每种实体牌分配一个带保护位的整数槽，使用一次带保护位的减法检查多重集合包含关系，再移除实体牌。保留原牌型池、稳定选项顺序、束宽、节点上限、浮点代价和截断上界。槽宽由最大实体重复数决定，支持测试中的非标准重复数，不假定所有输入恰有两份牌。原型不改变动作偏好，也不使用他人暗牌。

该整数实现已接入生产手牌规划，保持原单层 8192 项缓存。使用冻结的计数器实现，核对 576 副旧标签中的自身手牌及出牌后剩余牌，在束宽 6/24 下共 **11,272 个估值完全相等**。另有 160 个生成式多重集合案例，覆盖逢人配、不同束宽及超过标准双副牌的实体重复数。30 次默认固定选牌与 v8 相同，四组整队/混合质量对照的完整名次一致、配对收益差为零；这些质量对照不计作强度样本。

正式工作区全量 **933 项测试通过**，覆盖率 **84.87%**；Ruff、mypy（94 个源文件）及存档/会话/重放覆盖率分项门槛通过。缓存复制时曾出现双层包装，最终已恢复单层，并增加清缓存必须重新计算的测试。原始质量记录位于 `benchmarks/fast-hand-plan-v10/`。

停止其他计算任务后，729 个冷缓存样例串行交替执行冻结计数器与整数原型，涵盖 1～27 张、级牌 2/9/A、束宽 6/16/24；两者估值完全相等。规划核总耗时分别为 1.2454 秒和 0.2901 秒，即 **4.29 倍**。该数值仅描述这批规划调用，不是完整决策或对赛速度。

随后依次执行冻结计数器默认、整数默认及整数高手复核，各 42 次串行决策，**126 次全部满足原软时限**。默认两组总评估数由 9,986 增至 10,328（+3.4%），总时长由 30.62 秒至 30.13 秒；预算用满的搜索不会按规划核比例缩短时长。最高档一次开局由 252 次评估增至 282 次，最终选牌随截断位置变化；这与固定工作量下的精确等值不同。整数复核在部分开局取得 7～10 对完整样本，另有不足六对的局面仍明确回退，不能以速度替代强度验收。

对唯一改变的默认时钟动作另外标注 32 个共同世界、三档搭档及两条完整分支，共 192 条合法代理续局。新动作的平均代理收益差分别为 −0.023037 / −0.017351 / −0.017239，原始值保留在 `clock-action-diagnostic.json`。该案例说明多完成模拟并不保证选牌更好；规划优化的交付结论是确定性估值等值、计算效率提高，**没有验证实际对赛胜率提升**。

v9 现有数据始终使用冻结的计数器候选；整数实现不进入旧数据。其目的在于减少确定性计算开销，为有证据的后续搜索方案提供预算，不能单凭速度宣称胜率提升。

## 八对上限的预算校准（v11）

v11 对高手复核增加 **最多八对共同世界（16 次动作评估）** 的上限，保留至少六对的回退要求与原收益保护。第一阶段仍最多使用原工作量/时钟的一半，剩余预算只用于这八对；可提前结束，不填满无必要的评估。八对上限依据串行预算中常见的 7～10 对完成量选择，未使用独立对赛收益调参。

## 方法来源与边界

[Rollout Sampling Approximate Policy Iteration](https://arxiv.org/abs/0805.2027) 讨论将模拟资源分配给有价值的策略比较，支持本轮缩小专家复核集合的方向；本实现不是该论文算法的复现。[Using Common Random Numbers for Simulation-based Planning with Rollouts](https://arxiv.org/abs/2605.04732) 分析共同随机流对相对收益估计的方差影响，本轮继续保持候选共享暗牌世界。[DanZero+](https://arxiv.org/html/2312.02561v1) 使用完整回合收益训练动作模型，同时纳入整场结果；本项目的代理继续值和高手续局仍需本地独立对赛验证。
